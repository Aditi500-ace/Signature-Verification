# Signature Verification System

A full-stack AI-powered web application for real-time handwritten signature verification using Deep Learning and the MERN stack. The system analyzes uploaded signatures and predicts whether they are genuine or forged with high accuracy.

---

# 🚀 Project Overview

The Signature Verification System is designed to automate the process of verifying handwritten signatures using Deep Learning models integrated into a scalable web platform.

The application enables users to:
- Upload signature images
- Compare signatures in real time
- Detect forged signatures
- Receive prediction results instantly

The project combines:
- Deep Learning for image verification
- RESTful backend APIs
- Scalable MERN architecture
- Cloud deployment for production reliability

# 🧠 Deep Learning Workflow

1. User uploads a signature image
2. Image preprocessing is performed
3. Deep learning model extracts features
4. Signature is compared against trained patterns
5. Prediction result is returned instantly

